# Tournament Runner

A browser-based tournament management application built using core JavaScript, HTML, and CSS.

The goal of this project is not only to create a working tournament runner, but also to understand software architecture, state management, and real-world application flow using vanilla JavaScript.

---

# Project Vision

This project manages tournament flow from team registration to winner declaration.

The application should eventually support:

- Team registration
- Fixture generation
- Match progression
- Winner tracking
- Tournament persistence using local storage
- Dynamic rendering without page reloads

---

# Current Stack

- HTML
- CSS
- Vanilla JavaScript

No frameworks.

The purpose is to deeply understand:

- DOM manipulation
- Application state
- Business logic separation
- Rendering flow
- Persistence
- Event-driven architecture
