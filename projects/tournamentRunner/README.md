# Tournament Runner

A small browser-based tournament runner that stores competitors in local storage.

## How to use

- Open `index.html` in your browser.
- Add competitor names.
- Click **Draw Winner** to randomly select a winner.
- Use **Clear All** to reset the list.

## Files

- `index.html` — simple UI and script include.
- `css/styles.css` — minimal styling.
- `js/tournament.js` — main logic and local storage handling.
