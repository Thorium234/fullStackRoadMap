# Full Stack Roadmap

A personal hands-on learning repository for practicing and building projects using:

- HTML
- CSS
- JavaScript
- DOM Manipulation
- Responsive Design

This repository contains beginner to intermediate practice projects, UI experiments, DOM exercises, and mini applications built while learning frontend development fundamentals.

# Running the Projects

Most projects are static frontend projects.

You can run them by:
- Opening the HTML file directly in the browser
- Using VS Code Live Server extension

Example:

```bash
cd quizApp
```

Then open:

```text
index.html
```

in your browser.
